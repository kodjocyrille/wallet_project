# 💼 Pochi - Gestionnaire de portefeuille personnel

**Pochi** est une application mobile de gestion financière développée avec Flutter, conçue pour aider les utilisateurs à suivre leurs dépenses, revenus et économies de manière intuitive, en tenant compte des réalités africaines.

## ✨ Fonctionnalités

- 🔐 Authentification sécurisée (Firebase Auth)
- 📊 Suivi des dépenses et revenus
- 💸 Gestion des catégories personnalisées
- 📅 Historique des transactions
- ☁️ Synchronisation avec Firebase
- 🌙 Thème sombre et clair avec GetX
- 🔄 Navigation simplifiée grâce à GetX

## 🛠️ Technologies utilisées

- [Flutter](https://flutter.dev)
- [GetX](https://pub.dev/packages/get)
- [Firebase](https://firebase.google.com)
- [Dart](https://dart.dev)
